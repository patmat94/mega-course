A Cloudflare Worker named `rig-pulse` was deployed at `https://rig-pulse.patrykmatychniak.workers.dev` with two agents declared in `/.well-known/mega-pulse.json`: a pulse handler (reads the live tracker, replies with phrase + open issue + recommendation) and a test writer (calls Claude Haiku to write a failing test for the cited bug). Three claims were needed: the first was refused because the pulse `may` list included `comment`, `label`, and `close`; the second was refused because the test writer `may` list included `answer` and `comment`; the course accepted on the third claim after both lists were trimmed to one action each (`["answer"]` and `["test"]`). The Worker's `PING_KEY` and `ANTHROPIC_API_KEY` are stored as Cloudflare secrets — the next session can redeploy from `mega-s01e05/pulse-agent/` using `npx wrangler deploy` (already authenticated as `patrykmatychniak.workers.dev`). Key rule for future challenges: `may` lists in `mega-pulse.json` must list exactly what each agent does — the course checks them before sending any pings, so an extra action blocks all progress immediately.
